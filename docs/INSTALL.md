# Installing the app on a phone

Board Games Companion is a web app (PWA): there is no app store. You open a link once and
"install" it, which adds an icon to the home screen. It then opens full screen like a normal
app, keeps working offline for the games you download, and updates itself.

**Link:** https://whatweplay.pages.dev

Open the link in the phone's **real browser** (Chrome, Firefox, Samsung Internet or Safari).
Links opened inside WhatsApp, Telegram or Instagram open in a mini-browser that can't
install apps: use its "Open in browser" option first. Private/incognito tabs can't install either.

## Android

**Chrome** (most phones)

1. Open the link. Chrome may show an **"Install app"** banner — tap it and you're done.
2. Otherwise tap the **⋮** menu (top right) › **Add to Home screen** › **Install**.

**Firefox**

1. Open the link.
2. Tap the **⋮** menu (bottom right) › **More** › **Add app to Home screen** › **Add** (or
   drag the icon to where you want it). Older Firefox versions show it without **More**.

**Samsung Internet**

1. Open the link.
2. Tap the **≡** menu (bottom right) › **Add page to** › **Home screen** › **Add**.

The icon (a die on a yellow tile) appears on the home screen and in the app drawer.

## iPhone / iPad

1. Open the link in **Safari**. (On iOS 16.4 or later, Chrome, Firefox and Edge work too.)
2. Tap the **Share** button (square with an arrow ↑ — bottom bar on iPhone, top bar on iPad;
   on newer iOS it may sit under the **⋯** button).
3. Scroll down and tap **Add to Home Screen**.
4. Leave **Open as Web App** switched on (newer iOS), then tap **Add**.

Always open the app from the home-screen icon: that's the installed copy with its offline
downloads. The same site in a Safari tab keeps separate storage.

## First steps after installing

1. Open the app **while online** and pick your language (you can change it in ⚙ Settings).
2. Open each game you plan to play and tap **Download for offline** on its Learn tab.
   Allow storage if the browser asks. Now that game works with no connection; video clips
   still need the internet.
3. At the table the screen stays on while a guide is open.

## Updates and removal

- **Updates** are automatic: when the app is online it fetches the new version and uses it the
  next time you open it. If something looks old, close the app completely and reopen it.
- **Remove** it like any app: long-press the icon › Uninstall (Android) / Remove App ›
  Delete from Home Screen (iPhone). This also deletes its offline downloads.

## Troubleshooting

| Problem                                    | Fix                                                                        |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| No "Install"/"Add to Home Screen" option   | Open the link in the real browser, not inside a chat app or a private tab. |
| iPhone: the icon opens a normal Safari tab | Remove it and add it again with **Open as Web App** on.                    |
| A game says it needs a connection          | It wasn't downloaded: go online, open it, tap **Download for offline**.    |
| Pictures missing offline                   | Download the game again while online (it saves the pictures too).          |

## Italiano — in breve

È un'app web: niente store. Apri il link **https://whatweplay.pages.dev** nel
browser del telefono (non dentro WhatsApp/Telegram: usa "Apri nel browser").

- **Android (Chrome):** tocca il banner **Installa app**, oppure menu **⋮** › **Aggiungi a
  schermata Home** › **Installa**.
- **Android (Firefox):** menu **⋮** › **Altro** › **Aggiungi app alla schermata principale**.
- **Android (Samsung Internet):** menu **≡** › **Aggiungi pagina a** › **Schermata Home**.
- **iPhone/iPad:** in Safari tocca **Condividi** (quadrato con freccia ↑) › **Aggiungi alla
  schermata Home**, lascia attivo **Apri come app web** e tocca **Aggiungi**.

Poi apri l'app dall'icona **mentre sei online**, scegli la lingua e, per ogni gioco che userai,
tocca **Scarica per l'uso offline** nella scheda Impara: così funziona anche senza rete (i video
richiedono comunque la connessione). Gli aggiornamenti arrivano da soli; per rimuoverla,
tieni premuta l'icona e disinstalla.
